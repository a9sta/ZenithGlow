# 제니스글로우 (ZenithGlow)

출장마사지·홈타이 방문 안내 정적 사이트. 외부 의존성 없이 Node 20 표준 라이브러리만 쓴다.

## 돌리는 법

```bash
npm run regions   # 행정동 경계 → data/regions.json (원본 geojson 필요)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사 16종
npm run simil     # 동 안내문끼리 본문 겹침 측정
npm run serve     # dist/ 를 로컬에서 띄워 보기
```

## 호스팅 — Netlify

저장소를 Netlify 에 연결하거나 `dist/` 를 zip 으로 올린다. 빌드 설정은 아래와 같다.

| 칸 | 값 |
|---|---|
| Build command | `npm run build` |
| Publish directory | `dist` |
| 환경 변수 | `NODE_VERSION` = `20` |

- 기준 주소는 `data/site.config.json` 의 `siteUrl`. Netlify 는 빌드 때 `URL` 을 넣어 주므로 그 값이 먼저 쓰인다.
- Cloudflare 로 옮길 때는 `wrangler.jsonc`(main 없는 자산 전용 워커)가 이미 있다.
- `_headers` 와 `_redirects` 는 `dist/` 에 그대로 떨어진다. `301!` 는 Netlify 주소일 때만 붙는다.

## 이 사이트가 구하는 값 — 허리

땅이 가장 길게 뻗은 방향(넓이 가중 2차 모멘트)을 찾아 양 끝 사이를 **같은 길이의 열 토막**으로 나누고,
토막마다 땅 넓이를 반평면 절단(서덜랜드–호지먼)으로 그대로 잰다. 구멍은 음수로 뺀다.
열 넓이를 합쳐 100으로 맞춘 것이 열 토막 몫이고, 두꺼운 끝이 첫 토막이 되도록 방향을 정한다.

| 값 | 뜻 |
|---|---|
| 열 토막 몫 | 토막마다 땅이 전체의 몇 %인지 (합 100) |
| 허리값 | 셋째~여덟째 토막 중 가장 얇은 토막 ÷ 가장 두꺼운 토막 × 100 (낮을수록 잘록) |
| 두꺼운 토막 몫 | 열 토막 중 가장 큰 몫 |
| 긴 방향 길이 | 양 끝 사이 거리(km) |
| 허리 모양 | 위 값으로 가른 일곱 갈래: 아령꼴·잘록꼴·쐐기꼴·머리꼴·불룩꼴·방추꼴·고른꼴 |

## 커버리지

- **동까지** 서울·인천·경기·부산 — 1,232구역
- **시군구까지** 대전·대구·울산 전역 + 광주 광산구 + 지정 시·군
- 읍과 면은 안내문을 내지 않고 시군구 목록에 이름만 적는다(접수와 방문은 동일).

## 꼭 지킬 것

- `data/lastmod.json` 을 **반드시 커밋**한다. 없으면 깃 빌드에서 전 안내문이 '오늘 수정'으로 밀린다.
- 전화번호는 `callBox()` 으로만 찍는다. 맨 번호가 본문에 남으면 `npm run check` 가 잡는다.
- 무작위를 쓰지 않는다. 모든 변형은 md5 시드 고정이라 같은 주소면 언제나 같은 HTML 이 나온다.
- 후기·체험담·평점·인물 사진을 싣지 않는다.
